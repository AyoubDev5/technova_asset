# Technova assets

Public images for the Technova Salla theme: the block previews shown in Salla's theme editor
(`previews/`). Served through jsDelivr, for example:

```
https://cdn.jsdelivr.net/gh/AyoubDev5/technova_asset@<commit>/previews/faq.jpg
```

Links are pinned to a commit so a picture never changes under a published theme. The theme's source
code lives in a separate, private repository.

The pictures are screenshots of the theme's demo store. All rights reserved.
